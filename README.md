# Password-generator-Project
 🔐 Password Generator using Python

📌 Project Overview

The Password Generator is a Python-based application designed to generate strong and random passwords according to the length specified by the user.

The application combines uppercase letters, lowercase letters, numbers, and special characters to create a secure and unpredictable password.

🎯 Objectives

- To generate strong and random passwords.
- To allow users to specify the required password length.
- To include different types of characters for better password strength.
- To implement basic input validation.
- To practice Python programming concepts and built-in modules.

🚀 Features

- User-defined password length
- Random password generation
- Uppercase and lowercase letters
- Numbers and special characters
- Minimum length validation
- Simple command-line interface
- Instant password display

🛠️ Technologies Used

- Programming Language: Python
- Modules: "random", "string"
- Interface: Command Line Interface (CLI)

⚙️ How It Works

1. The user enters the required password length.
2. The program validates the entered length.
3. One uppercase letter, lowercase letter, digit, and special character are selected.
4. Additional characters are randomly generated to complete the password.
5. The characters are shuffled to create a random password.
6. The generated password is displayed to the user.

▶️ How to Run

Clone the repository and open the project folder.

Run the following command:

python password_generator.py

Enter the desired password length when prompted.

💻 Sample Output

       PASSWORD GENERATOR

Enter password length: 10
Generated Password: G7@kp2#LmX
Password generated successfully!

«Note: The generated password will be different each time because the program uses random generation.»
